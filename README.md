# A Little Surprise for Mansi 💗

A small, mobile-first birthday surprise website made with plain HTML, CSS, JavaScript, and local PNG artwork. It has no external libraries, no sound, and no tracking code added by this project.

## Preview locally

Open `index.html` in a modern browser. Keep the `assets` folder beside it.

## Publish free with GitHub Pages

1. Create a **public** GitHub repository named `a-little-surprise-for-mansi`.
2. Upload the contents of this project folder (`index.html`, `assets/`, and this README) to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait for GitHub Pages to publish, then open the site URL shown on the Pages settings screen.

The website is public when published. Do not add private information or anything you would not want anyone with the link to see.
